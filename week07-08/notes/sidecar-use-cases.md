# Sidecar uses cases

Sidecar pattern allows you to extend the main app's functionality without changing the main app's source code. It decouples the main app from the extended functionalities, each container in the pod can focus on its core responsibility (seperation of concerns). This is possible because containers in the same pod share storage (volumes) and networks.

In the lab, the nginx web server was the main app and busybox was the sidecar. Busybox's responsibility was writing the date and timestamp into a index.html file. Because both containers share the same storage, the nginx web server can serve the html file generated by the sidecar.
