# Sidecar uses cases

Sidecar pattern allows you to extend the main app's functionality without changing the main app's source code. It decouples the main app from the extended functionalities, each container in the pod can focus on its core responsibility (seperation of concerns).

Containers can share data with each other through a volume. In the lab, both containers were mounted to the same emptyDir volume. Busybox mounted the volume at /data and nginx mounted it at /usr/share/nginx/html. Both those paths point to the same volume. Busybox container writes date > /data/index.html, /data is the mount path that points to the shared emptyDir volume, so index.html is stored in the emptyDir volume. Nginx serves files from /usr/share/nginx/html which is also mounted to the same emptyDir volume. Busybox is the writer and nginx is the reader, both have their own responsibilites (seperation of concerns).
